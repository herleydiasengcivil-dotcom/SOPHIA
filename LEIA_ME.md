# Arquivos CAD para download

- Q194_completo.zip: lotes 6 a 10 da quadra 194, Bairro Dominguinhos, Montanha/ES.
- Q56_completo.zip: lotes 02 e 03 da quadra 56, Residencial Pelourinho, Montanha/ES.

Os pacotes incluem DWG, DXF, PDF e orientações de uso.
Os arquivos foram reconstruídos dos PDFs fornecidos; as limitações de precisão e conferência estão registradas nos documentos de cada pacote.

Para baixar, abra o ZIP desejado no GitHub e use o botão de download do arquivo bruto. Também é possível baixar ambos em Code > Download ZIP.
